What this radar does not do

  • It does not predict whether or when a protocol issues a token. The implied value is this entry's claim about what a token would be worth if the protocol's record stayed as it is.
  • It says a protocol records no token, never that it has none: a DefiLlama record can miss a token.
  • Growth (7d) and age (time with no token) are not in the formula. Both were tested as extra regressors in the leave-one-out backtest and neither improved it, so they are shown as context only.
  • Farmers and EV per farmer are order-of-magnitude estimates from TVL and chain count, shown as a range (×0.5–×2). The point EV assumes 10% of the implied value reaches the farming community.
